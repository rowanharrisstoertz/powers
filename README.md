# powers Package

This is a minimal working example of my first R Package for STAT545!

## Installation

Package installation can be done directly by calling

``` r
devtools::install_github("rharrisstoertz/powers")
```

## Example

This is a basic example which shows you how to use the `square` function
from `powers`:

``` r
library(powers)
square(c(2,4,5))
#> [1]  4 16 25
```
